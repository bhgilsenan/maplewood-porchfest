## 2025 Amenities Map (Google My Maps) — restrooms, honk parade, restaurants, playground, parking

https://www.google.com/maps/d/u/0/viewer?ll=40.71960941572022%2C-74.26728185586161&z=17&mid=104gsJoDg8CTzRXmq1du62-8u-EdAXtA

Different map ID from the one above — this is the "stripped down" copy Tracy sent alongside `Copy 2025 Google Maps of Public Restrooms, etc_.docx` (in `data/2025-reference/`). Per her note: mostly reusable for 2026 with a few add-ons; Perla Oysters (Jacoby & Boyden) was marked closed last year, TBD which restaurants are open Sunday 9/6/2026.

**To reuse for 2026:** open this map in My Maps → for each layer (Honk Parade Route, Restrooms, Restaurants, Playground, Parking) use the layer's ⋮ menu → Export to KML/KMZ → then in the new 2026 map, Add Layer → Import → upload that KML. This copies the exact geometry/pins without manual redrawing.
